Category: Cultural Heritage / Public Narratives. Narrates *community identity*,
with a critical angle on poverty, survival and the sachet economy.

## Design decisions (v1)

**Palette** (taken from store paint, signboards and sachet packaging)

| Name | Hex | Use |
|------|-----|-----|
| Kahoy brown | `#2B1D14` | Text, frames, grill |
| Papel cream | `#F6EBD3` | Page backgrounds |
| Karatula red | `#B8382A` | Signs, buttons |
| Sachet yellow | `#F2B705` | Highlights, hover |
| Pintura teal | `#1F6F78` | Walls, links |

**Typefaces** (Google Fonts)

- **Bungee**: headings, looks like painted signage
- **Nunito Sans**: body text, stories, captions
- **Caveat**: handwritten listahan accents

## Elements and principles: where they will appear

| | In our site |
|---|---|
| Line | Rehas grill bars frame every page |
| Color | Loud sachet and signboard palette |
| Texture | Plywood, paint, plastic sachets |
| Perspective | Looking into the store through the window |
| Form/Shape | Jars, bottles, sachet strips |
| Space | Packed but readable shelves |
| Balance | Centered sign, symmetric shelves |
| Rhythm | Repeated rows of hanging sachets |
| Emphasis | The hand-painted store sign |
| Harmony | One palette, one type system |
| Proportion | Big sign, small sachets |
